Module 01: Foundational Skills
Essential Standard
Students will recognize and evaluate functions using function notation, simplify expressions involving exponents and radicals, apply basic trigonometry to right triangles using special angles and the six trigonometric ratios, and solve real-world problems involving angles, sides, and forces in triangles using trigonometric relationships.
Section 1.A: Recognize Functions and Evaluate Expressions Given in Function Notation
Learning Objectives – I can…
•  Determine whether a set of ordered pairs represents a function by applying the definition of a function and the vertical line test.
•  Identify functions given by equations by reasoning about whether each input produces exactly one output.
•  Evaluate function expressions at Level 1 by substituting given values into function notation and simplifying.
Section 1.B: Simplify Expressions with Exponents and Radicals
Learning Objectives – I can…
•  Rewrite exponential expressions by applying the product, quotient, power, zero, and negative exponent rules.
•  Evaluate basic exponential functions by substituting values and applying properties of exponents to simplify.
•  Plug values into exponential formulas and evaluate, attending to precision when working with growth and decay models.
Section 1.C: Apply Basic Trigonometry to Right Triangles
Learning Objectives – I can…
•  Find exact side lengths in special right triangles (30-60-90 and 45-45-90) and express answers in radical form.
•  Evaluate sine, cosine, and tangent for angles not on the unit circle using right triangle ratios.
•  Determine exact values of trigonometric functions for special angles using structure and repeated reasoning.
Section 1.D: Apply Trigonometry to Real World Problems
Learning Objectives – I can…
•  Find unknown angles in a right triangle using inverse trigonometric functions and attend to precision in degree measure.
•  Find unknown sides in a right triangle by selecting and applying the appropriate trigonometric ratio.
•  Solve real-world force problems by applying trigonometry to decompose vectors and analyze triangle relationships.
Above and Beyond: Extended Learning (Section 1.E)
Learning Objectives for Above and Beyond – I can…
•  Find the average rate of change of a function from a table of values by calculating the ratio of change in output to change in input over a specified interval.
•  Find the average rate of change of a function from an equation by evaluating the function at the endpoints of a given interval and applying the rate of change formula.
•  Find the average rate of change from a graph by identifying output values at two points and reasoning about the slope of the secant line over the interval.
•  Interpret the average rate of change in context by attaching appropriate units and explaining the meaning of the rate in the situation.

Assessment Methods
Rung 1:Function identification activities using sets of points, tables, and mapping diagrams
Rung 2:Function notation evaluation tasks and equation-based function identification
Rung 3:Exponent rule rewriting tasks and exponential formula evaluation problem sets
Rung 4:Special right triangle exact value tasks with radical expression answers
Rung 5:Trigonometric exact value assessments and non-unit circle ratio problems
Rung 6:Average rate of change tasks from tables, equations, and graphs over specified intervals
Rung 7:Contextual rate of change problems requiring unit interpretation and written explanation
