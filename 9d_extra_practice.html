9.D Solve Polynomial Equations

Extra Practice

Level 1 — Basic Factoring

Solve each equation.

  1. \( x^2 - 7x + 10 = 0 \)
  2. \( x^2 - 16 = 0 \)
  3. \( x(x-5)=0 \)
  4. \( x^2 + 2x - 8 = 0 \)

Solve each equation.

  1. \( x^3 - 3x^2 = 0 \)
  2. \( x^3 - 2x^2 - 8x = 0 \)
  3. \( x(x+3)(x-4)=0 \)
  4. \( x^3 - 16x = 0 \)

Determine if a solution exists.

  1. \( x^2 + 4 = 0 \)
  2. \( x^4 + 9 = 0 \)
  3. \( x(x^2+4)=0 \)
  4. \( x^2 - 6x + 9 = 0 \)

Level 2 — Factoring + Structure

Factor and solve.

  1. \( x^3 - 5x^2 - 6x = 0 \)
  2. \( x^4 - 9x^2 = 0 \)
  3. \( x^3 + 3x^2 - 4x - 12 = 0 \)
  4. \( x^4 - 2x^3 - 8x^2 + 16x = 0 \)

Use grouping to solve.

  1. \( x^3 + x^2 - 6x - 6 = 0 \)
  2. \( x^3 - 2x^2 - 9x + 18 = 0 \)
  3. \( x^4 + 3x^3 - x^2 - 3x = 0 \)
  4. \( x^4 - 4x^3 + x^2 + 4x = 0 \)

Solve and list all solutions.

  1. \( x^2 - 6x + 9 = 0 \)
  2. \( x^3 - 6x^2 + 12x - 8 = 0 \)
  3. \( x^4 - 10x^2 + 25 = 0 \)
  4. \( x^3 - 4x^2 - x + 4 = 0 \)

Level 3 — Synthetic Division

Use synthetic division to solve.

  1. \( x^3 - 3x^2 - x + 3 = 0 \)
  2. \( x^3 - 5x^2 + 2x + 8 = 0 \)
  3. \( x^3 - 2x^2 - 9x + 18 = 0 \)
  4. \( x^3 + 2x^2 - 13x - 10 = 0 \)

Solve completely.

  1. \( x^4 - 3x^3 - 10x^2 + 24x = 0 \)
  2. \( x^4 - 6x^3 + 5x^2 + 30x = 0 \)
  3. \( x^4 - 2x^3 - 13x^2 + 14x + 24 = 0 \)
  4. \( x^4 - 4x^3 - x^2 + 16x - 12 = 0 \)

Verify solutions.

  1. \( x^3 - 3x^2 - x + 3 = 0 \)
  2. \( x^3 - 6x^2 + 12x - 8 = 0 \)
  3. \( x^4 - 9x^2 = 0 \)
  4. \( x^4 + 3x^3 - x^2 - 3x = 0 \)

Level 4 — Full Structural Solving

Solve completely. Show all steps.

  1. \( x^3 - 3x^2 - 4x + 12 = 0 \)
  2. \( x^3 - 5x^2 + 4x + 12 = 0 \)
  3. \( x^3 - 8x^2 + 15x = 0 \)
  4. \( x^3 - 6x^2 + 5x = 0 \)
  5. \( x^4 - 10x^2 + 25 = 0 \)
  6. \( x^4 - 16x^2 = 0 \)
  7. \( x^4 - 3x^3 - 10x^2 + 24x = 0 \)

Solve and graph.

  1. \( x^3 - 3x^2 - 4x + 12 = 0 \)
  2. \( x^3 - 2x^2 - 9x + 18 = 0 \)
  3. \( x^4 - 16x^2 = 0 \)
  4. \( x^3 - 6x^2 + 12x - 8 = 0 \)

Describe graph behavior at each solution.

  1. \( x^2 - 6x + 9 = 0 \)
  2. \( x^3 - 6x^2 + 12x - 8 = 0 \)
  3. \( x^3 - 3x^2 - 4x + 12 = 0 \)
  4. \( x^4 - 16x^2 = 0 \)

Level 5 — Justification

  1. Explain why factoring must be complete before solving.
  2. Explain how roots relate to graph intercepts.
  3. Justify when synthetic division is useful.
  4. Explain multiplicity and graph behavior.
  5. Describe how graphs confirm solutions.
