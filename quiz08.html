Answer Key — Module 08 Quizzes

Quiz 08 v1

1. $6x^3 - 24x = 6x(x^2 - 4) = 6x(x-2)(x+2)$

2. $\frac{x^2 - 36}{x - 6} = x + 6 \quad (x \ne 6)$

3. $x + 3 \quad (x \ne 0,\,3)$

4. $x^2 - 2 \quad \text{remainder } 0$

5. $4$; removable discontinuity

6. $-\infty$ and $+\infty$; does not exist

Quiz 08 v2

1. $x^2 + 0x + 10$

2. $5x(x^2 - 4) = 5x(x-2)(x+2)$

3. $x + 5 \quad (x \ne 0,\,5)$

4. $x + 7 \quad (x \ne 7)$

5. $-6$; removable discontinuity

6. $-\infty$ and $+\infty$; no two-sided limit

Quiz 08 v3

1. $x + 10 \quad (x \ne 10)$

2. $x^2 - x - 6$

3. $9x(x^2 - 9) = 9x(x-3)(x+3)$

4. $x + 6 \quad (x \ne 0,\,6)$

5. $-8$; removable discontinuity

6. $-\infty$ and $+\infty$; does not exist

Quiz 08 v4

1. $x^2 - 2x - 1 \quad \text{remainder } 2$

2. $12x(x^2 - 9) = 12x(x-3)(x+3)$

3. $x + 12 \quad (x \ne 12)$

4. $x + 4 \quad (x \ne 0,\,4)$

5. $-6$; removable discontinuity

6. Jump discontinuity; limit does not exist

Quiz 08 v5

1. $\frac{x^2 - x + 1}{3}$

2. $3x^2 - x - 5$

3. $\frac{4(x-3) + 5x}{x(x-3)} = \frac{9x - 12}{x(x-3)}$

4. $(3x^2 - 2)(2x + 3)$

5. Infinite limit; vertical asymptote at $x=1$

6. $\frac{x^2 - 4}{x - 2} = x + 2$; removable discontinuity at $x=2$

Quiz 08 v6

3. $x + 5 \quad (x \ne 0,\,5)$

4. $(x - 5)(x^2 + 5x + 25)$

6. Jump discontinuity; limit does not exist

Module 08 Quiz Rubric

Overall Structure

  • Questions 1–4: Essential Skills
  • Questions 5–6: Above & Beyond
  • Work must be shown for full credit.

Essential Skills (Questions 1–4)

Grade Description
A Complete understanding demonstrated. All structural steps shown. Factoring is complete. Restrictions identified. Division process clear. Minor computational error does not reduce mastery level.
B Strong understanding with one significant procedural error OR missing structural element. Work mostly clear and logically organized.
C Partial understanding. Correct method identified but multiple execution errors OR incomplete reasoning.
D Limited understanding. Attempt made but structural reasoning is weak or inconsistent.
Not Yet Little to no evidence of understanding. Work missing or unrelated.

Above & Beyond (Questions 5–6)

Grade Description
A Correct computation AND precise mathematical explanation. Uses correct terminology (removable, infinite, jump, asymptote). Clear logical reasoning.
B Correct conclusion with explanation that lacks precision or full justification.
C Correct direction but incomplete reasoning or terminology errors.
D Minimal explanation; reasoning unclear or inconsistent.
Not Yet No meaningful explanation or incorrect conceptual reasoning.

Professional Expectations

  • All work must be shown.
  • Factoring must be complete.
  • Restrictions must be stated clearly.
  • Division remainders must be written correctly.
  • Limit classifications must include reasoning.
  • Mathematical notation must be precise.
