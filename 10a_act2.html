Numbered Heads Together
Numbered Heads Together
Setup: Groups of 4. Each person takes a number: 1, 2, 3, or 4.
  1. Solve Together: Work as a group to solve the problem. Make sure every person understands every step.
  2. Teach Each Other: If someone is unclear on a step, the group teaches them before moving on.
  3. Be Ready: The teacher will call a number. The student with that number explains the solution for the class.
  4. Standard: The group succeeds only when every member could be called and explain the solution fully.
✓ Looks Like Success
  • Every member can explain the full solution — not just the answer
  • Group checks understanding before declaring done
  • The called student explains reasoning, not just steps
✗ What to Avoid
  • Letting one person do all the talking during group work
  • Moving on before everyone understands
  • The called student saying 'I don't know' — that means the group isn't done yet

\( \log(xy) \)

\( \log x + \log y \)

Problem 16
