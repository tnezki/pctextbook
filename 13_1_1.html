Given the function \(f(x)=\frac{x+2}{(x+1)^2}\).

  1. Use a calculator to create a table for \(f(x)\). As \(x\to\infty\), describe what happens to \(f(x)\).
  2. Describe how the table values are reflected in the graph of \(y=f(x)\).
  3. Make a table for \(-3\le x\le 1\) using increments of \(0.2\). Use your table values to evaluate the following limits: \(\lim\limits_{x\to -1^-} f(x)\) and \(\lim\limits_{x\to -1^+} f(x)\).
  4. What happens in the table at \(x=-1\)? How is this reflected in the graph?
