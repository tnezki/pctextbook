10.C Solving Exponential and Logarithmic Equations

Stations

Station 1
Solve each equation by rewriting with a common base when possible.
  1. $$2^x=32$$
  2. $$3^x=81$$
  3. $$4^x=64$$
  4. $$8^x=2^9$$
  5. $$9^x=3^6$$
  6. $$5^{x-1}=125$$
Station 1 Solutions
  1. $$2^x=2^5\Rightarrow x=5$$
  2. $$3^x=3^4\Rightarrow x=4$$
  3. $$4^x=4^3\Rightarrow x=3$$
  4. $$\left(2^3\right)^x=2^9\Rightarrow 2^{3x}=2^9\Rightarrow x=3$$
  5. $$\left(3^2\right)^x=3^6\Rightarrow 3^{2x}=3^6\Rightarrow x=3$$
  6. $$5^{x-1}=5^3\Rightarrow x-1=3\Rightarrow x=4$$
Station 2
Rewrite each logarithmic equation in exponential form and solve.
  1. $$\log x=2$$
  2. $$\log_2 x=5$$
  3. $$\log_3 x=4$$
  4. $$\ln x=1$$
  5. $$\log_5(x)=3$$
  6. $$\ln(x)=2$$
Station 2 Solutions
  1. $$x=10^2=100$$
  2. $$x=2^5=32$$
  3. $$x=3^4=81$$
  4. $$x=e^1=e$$
  5. $$x=5^3=125$$
  6. $$x=e^2$$
Station 3
Use logarithm properties to combine first, then solve. Check for valid answers.
  1. $$\log x+\log(x-1)=\log 12$$
  2. $$\log(x+2)-\log x=\log 2$$
  3. $$2\log x=\log 49$$
  4. $$\log(x+4)+\log(x-1)=\log 36$$
  5. $$\ln x+\ln(x-3)=\ln 28$$
Station 3 Solutions
  1. $$x(x-1)=12\Rightarrow x^2-x-12=0\Rightarrow x=4,-3$$ Valid: $$x=4$$
  2. $$\frac{x+2}{x}=2\Rightarrow x+2=2x\Rightarrow x=2$$
  3. $$\log(x^2)=\log 49\Rightarrow x^2=49$$ Valid: $$x=7$$
  4. $$ (x+4)(x-1)=36\Rightarrow x^2+3x-40=0\Rightarrow x=5,-8$$ Valid: $$x=5$$
  5. $$x(x-3)=28\Rightarrow x^2-3x-28=0\Rightarrow x=7,-4$$ Valid: $$x=7$$
Station 4
Solve each multi-step exponential equation.
  1. $$2^{x+1}=16$$
  2. $$3^{x-2}=27$$
  3. $$5^{2x}=125$$
  4. $$2^{x+3}=64$$
  5. $$4^{x-1}=16$$
  6. $$9^{x+1}=27$$
Station 4 Solutions
  1. $$2^{x+1}=2^4\Rightarrow x+1=4\Rightarrow x=3$$
  2. $$3^{x-2}=3^3\Rightarrow x-2=3\Rightarrow x=5$$
  3. $$5^{2x}=5^3\Rightarrow 2x=3\Rightarrow x=\frac{3}{2}$$
  4. $$2^{x+3}=2^6\Rightarrow x+3=6\Rightarrow x=3$$
  5. $$4^{x-1}=4^2\Rightarrow x-1=2\Rightarrow x=3$$
  6. $$3^{2x+2}=3^3\Rightarrow 2x+2=3\Rightarrow x=\frac12$$
Station 5
When no convenient common base exists, solve using logarithms.
  1. $$2^x=7$$
  2. $$3^x=11$$
  3. $$5^{x-1}=9$$
  4. $$e^{2x}=10$$
  5. $$7^{x+2}=20$$
Station 5 Solutions
  1. $$x=\log_2 7=\frac{\ln 7}{\ln 2}$$
  2. $$x=\log_3 11=\frac{\ln 11}{\ln 3}$$
  3. $$x-1=\log_5 9\Rightarrow x=1+\log_5 9$$
  4. $$2x=\ln 10\Rightarrow x=\frac{\ln 10}{2}$$
  5. $$x+2=\log_7 20\Rightarrow x=\log_7 20-2$$
Station 6
Compare equations, determine solutions, and notice how structure changes the answer.
  1. Solve both: $$\log x=2 \quad \text{and} \quad \log(x-2)=2$$
  2. Solve both: $$2^x=8 \quad \text{and} \quad 2^{x+1}=8$$
  3. Solve both: $$\ln x=3 \quad \text{and} \quad \ln(x+1)=3$$
  4. Solve both: $$3^x=27 \quad \text{and} \quad 3^{x-2}=27$$
  5. Explain in one sentence how a horizontal shift inside the input changes the solution.
Station 6 Solutions
  1. $$\log x=2\Rightarrow x=100$$ and $$\log(x-2)=2\Rightarrow x-2=100\Rightarrow x=102$$
  2. $$2^x=8\Rightarrow x=3$$ and $$2^{x+1}=8\Rightarrow x+1=3\Rightarrow x=2$$
  3. $$\ln x=3\Rightarrow x=e^3$$ and $$\ln(x+1)=3\Rightarrow x+1=e^3\Rightarrow x=e^3-1$$
  4. $$3^x=27\Rightarrow x=3$$ and $$3^{x-2}=27\Rightarrow x-2=3\Rightarrow x=5$$
  5. A horizontal shift inside the expression changes the value that must equal the solved quantity, so the final answer shifts accordingly.
