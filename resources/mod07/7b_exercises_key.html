7.B Exercises — Answer Key

1.
$1 - \cos^2\theta = \sin^2\theta$
$\dfrac{\sin^2\theta}{\sin^2\theta} = 1$
2.
$\cos(2\theta) = 1 - 2\sin^2\theta$
3.
$\sec^2\theta - 1 = \tan^2\theta$
$\dfrac{\tan^2\theta}{\tan^2\theta} = 1$
4.
Factor: $(\sin^2\theta - \cos^2\theta)(\sin^2\theta + \cos^2\theta)$
$= -(\cos^2\theta - \sin^2\theta)(1) = -\cos(2\theta)$
5.
$1 + \cos(2\theta) = 2\cos^2\theta$
$1 - \cos(2\theta) = 2\sin^2\theta$
$= \dfrac{\cos^2\theta}{\sin^2\theta} = \cot^2\theta$
6.
$\sin(2\theta) = 2\sin\theta\cos\theta$
$\dfrac{2\sin\theta\cos\theta}{\cos\theta} = 2\sin\theta$
7.
7–24–25 triangle ⇒ $\sin\theta = \dfrac{7}{25}$
$\sin(2\theta) = 2\left(\dfrac{7}{25}\right)\left(\dfrac{24}{25}\right)$
$= \dfrac{336}{625}$
8.
Rewrite using $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$:
Multiply numerator and denominator by $\cos^2\theta$
$\dfrac{\cos^2\theta - \sin^2\theta}{\cos^2\theta + \sin^2\theta} = \cos(2\theta)$ ✓
