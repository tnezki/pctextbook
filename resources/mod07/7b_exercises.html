7.B Exercises

1. Simplify completely: \[ \frac{1 - \cos^2\theta}{\sin^2\theta} \]
2. Rewrite using sine only: \[ \cos(2\theta) \]
3. Simplify completely: \[ \frac{\sec^2\theta - 1}{\tan^2\theta} \]
4. Simplify completely: \[ \sin^4\theta - \cos^4\theta \]
5. Simplify completely: \[ \frac{1 + \cos(2\theta)}{1 - \cos(2\theta)} \]
6. Simplify completely: \[ \frac{\sin(2\theta)}{\cos\theta} \]
7. If \[ \cos\theta = \frac{24}{25} \] and $\theta$ is in Quadrant I, find $\sin(2\theta)$.
8. Verify: \[ \frac{1 - \tan^2\theta}{1 + \tan^2\theta} = \cos(2\theta) \]
