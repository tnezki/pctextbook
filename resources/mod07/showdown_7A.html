Problem 1
Evaluate $\sin\left(\frac{\pi}{6}\right)$.
Problem 1 — Solution
$\frac{\pi}{6}$ is in Quadrant I. Reference angle = $\frac{\pi}{6}$. $\sin = \frac{1}{2}$
Problem 2
Evaluate $\cos\left(\frac{\pi}{3}\right)$.
Problem 2 — Solution
Quadrant I → cosine positive. $\cos = \frac{1}{2}$
Problem 3
Evaluate $\tan\left(\frac{\pi}{4}\right)$.
Problem 3 — Solution
$\tan = \frac{\sin}{\cos} = \frac{\sqrt2/2}{\sqrt2/2} = 1$
Problem 4
Evaluate $\sin\left(\frac{\pi}{3}\right)$.
Problem 4 — Solution
Quadrant I. $\sin = \frac{\sqrt3}{2}$
Problem 5
Evaluate $\cos\left(\frac{\pi}{4}\right)$.
Problem 5 — Solution
Quadrant I. $\cos = \frac{\sqrt2}{2}$
Problem 6
Evaluate $\tan\left(\frac{\pi}{6}\right)$.
Problem 6 — Solution
$\tan = \frac{1/2}{\sqrt3/2} = \frac{\sqrt3}{3}$
Problem 7
Evaluate $\sin\left(\frac{2\pi}{3}\right)$.
Problem 7 — Solution
Quadrant II → sine positive. Reference angle = $\frac{\pi}{3}$. $= \frac{\sqrt3}{2}$
Problem 8
Evaluate $\cos\left(\frac{3\pi}{4}\right)$.
Problem 8 — Solution
Quadrant II → cosine negative. Reference $\frac{\pi}{4}$. $= -\frac{\sqrt2}{2}$
Problem 9
Evaluate $\tan\left(\frac{5\pi}{6}\right)$.
Problem 9 — Solution
Quadrant II → tangent negative. Reference $\frac{\pi}{6}$. $= -\frac{\sqrt3}{3}$
Problem 10
Evaluate $\sin\left(\frac{4\pi}{3}\right)$.
Problem 10 — Solution
Quadrant III → sine negative. Reference $\frac{\pi}{3}$. $= -\frac{\sqrt3}{2}$
Problem 11
Evaluate $\cos\left(\frac{5\pi}{3}\right)$.
Problem 11 — Solution
Quadrant IV → cosine positive. Reference $\frac{\pi}{3}$. $= \frac{1}{2}$
Problem 12
Evaluate $\tan\left(\frac{7\pi}{4}\right)$.
Problem 12 — Solution
Quadrant IV → tangent negative. Reference $\frac{\pi}{4}$. $= -1$
Problem 13
Evaluate all six trig functions for $\theta=\frac{3\pi}{4}$.
Problem 13 — Solution
Coordinates: $\left(-\frac{\sqrt2}{2},\frac{\sqrt2}{2}\right)$ $\sin=\frac{\sqrt2}{2}$ $\cos=-\frac{\sqrt2}{2}$ $\tan=-1$ $\csc=\sqrt2$ $\sec=-\sqrt2$ $\cot=-1$
Problem 14
Evaluate all six trig functions for $\theta=\frac{5\pi}{6}$.
Problem 14 — Solution
Coordinates: $\left(-\frac{\sqrt3}{2},\frac{1}{2}\right)$ $\sin=\frac{1}{2}$ $\cos=-\frac{\sqrt3}{2}$ $\tan=-\frac{\sqrt3}{3}$ $\csc=2$ $\sec=-\frac{2\sqrt3}{3}$ $\cot=-\sqrt3$
Problem 15
Explain why $\tan\left(\frac{3\pi}{4}\right)$ is negative.
Problem 15 — Solution
$\frac{3\pi}{4}$ is in Quadrant II. In Quadrant II, sine is positive and cosine is negative. Since $\tan=\frac{\sin}{\cos}$, positive ÷ negative = negative.
Problem 16
Explain why $\cos\left(\frac{4\pi}{3}\right)$ is negative.
Problem 16 — Solution
$\frac{4\pi}{3}$ lies in Quadrant III. Cosine is the x-coordinate. In Quadrant III, x-values are negative.
Problem 17
Determine the sign of $\sin\left(\frac{11\pi}{6}\right)$ without evaluating the reference value.
Problem 17 — Solution
$\frac{11\pi}{6}$ is in Quadrant IV. Sine (y-coordinate) is negative in Quadrant IV.
Problem 18
Determine the sign of $\tan\left(\frac{7\pi}{6}\right)$.
Problem 18 — Solution
Quadrant III. Sine and cosine are both negative. Negative ÷ negative = positive. Tangent is positive.
Problem 19
Justify why $\sin\left(\frac{2\pi}{3}\right)$ and $\sin\left(\frac{\pi}{3}\right)$ have the same magnitude.
Problem 19 — Solution
They share the same reference angle $\frac{\pi}{3}$. Sine depends on the reference angle’s y-value. Only the sign changes by quadrant.
Problem 20
Describe the process for evaluating any trig function on the unit circle.
Problem 20 — Solution
1. Determine the quadrant. 2. Find the reference angle. 3. Recall the Quadrant I value. 4. Apply the correct sign. 5. Use ratios if evaluating tangent, secant, csc, or cot.
