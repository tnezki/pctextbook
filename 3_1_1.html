Operations with Rational Expressions
3-4

Multiply or divide each of the following expressions. Simplify the result, if possible. State the values of the variable that need to be excluded.

  1. \(\large \frac { 12 ( x + 9 ) ^ { 4 } } { 8 x } \cdot \frac { x ^ { 2 } + 5 x } { ( x + 9 ) ^ { 12 } }\)

  2. \(\large \frac { 5 x ^ { 2 } - 14 x - 3 } { x ^ { 2 } - 9 } \div \frac { 5 x ^ { 2 } + 6 x + 1 } { 2 x ^ { 2 } + x - 1 }\)

  3. \(\large \frac { x ^ { 3 } - 16 x } { x ^ { 6 } } \cdot \frac { 3 - 2 x } { 2 x ^ { 2 } + 5 x - 12 }\)
