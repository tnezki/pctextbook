10.B Graph Exponential and Logarithmic Functions

Exponential and logarithmic functions describe relationships involving growth and decay. While exponential functions model rapid change, logarithmic functions allow us to reverse that process and analyze structure.
Understanding these functions requires identifying key features such as domain, range, intercepts, and asymptotes, as well as recognizing how transformations affect their graphs.
“Exponential growth and logarithmic scaling describe how systems change and how we measure that change.”

Introduction

Exponential functions represent repeated multiplication and describe rapid growth or decay. Logarithmic functions are their inverses and allow us to determine how many times a base must be multiplied to reach a value.

Although these functions behave differently, they are closely connected. Understanding their structure helps us analyze real-world relationships involving growth, decay, and scaling.

Key Idea: Exponential and logarithmic functions are inverses that describe opposite processes.

History

Exponential growth has been studied for centuries in relation to population and finance. Logarithms were introduced in the 17th century to simplify calculations involving exponential relationships.

John Napier and Henry Briggs developed logarithms to make multiplication and division easier, which was critical before modern calculators.

Today, exponential and logarithmic functions are essential tools in science, engineering, and mathematics.

Key Concepts

Exponential Functions

An exponential function has the form:

$$ f(x)=a^x \quad \text{where } a>0,\ a\neq1 $$

These functions model repeated multiplication and describe growth or decay.

Key Idea: Exponential functions change by a constant multiplicative factor.

Logarithmic Functions

A logarithmic function is the inverse of an exponential function.

$$ f(x)=\log_b x \iff b^y=x $$

Logarithms tell us what exponent is needed to produce a value.

Domain and Range

These functions have different restrictions.

  • Exponential: Domain = all real, Range = \(y>0\)
  • Logarithmic: Domain = \(x>0\), Range = all real
Important: Logarithms are undefined for nonpositive values.

Asymptotes

Exponential and logarithmic functions each have characteristic asymptotes.

  • Exponential: horizontal asymptote \(y=0\)
  • Logarithmic: vertical asymptote \(x=0\)

These asymptotes describe how the graph behaves near extreme values.

Key Points

Each function has standard points that help sketch the graph.

  • Exponential: \( (0,1) \)
  • Logarithmic: \( (1,0) \)

These points act as anchors when graphing.

Transformations

Transformations shift or reflect the graph.

  • \( f(x-h) \): shift right
  • \( f(x)+k \): shift up
  • \( -f(x) \): reflection across x-axis

These change position but not the overall shape.

Inverse Relationship

Exponential and logarithmic functions are inverses.

$$ y=a^x \quad \text{and} \quad y=\log_a x $$

Their graphs reflect across the line \(y=x\).

Key Idea: Inverse functions undo each other.

Vocabulary

Exponential Function:

A function of the form \(f(x)=a^x\) representing growth or decay.

Logarithmic Function:

The inverse of an exponential function, written \(f(x)=\log_a x\).

Asymptote:

A line that a graph approaches but does not reach.

Domain:

The set of all possible input values.

Range:

The set of all possible output values.

Transformation:

A change in the graph such as a shift, reflection, or stretch.

Strategies

Graphing Exponential Functions:

  1. Identify the base and determine growth or decay
  2. Plot key points such as \((0,1)\)
  3. Identify horizontal asymptote \(y=0\)
  4. Sketch smooth curve through points

Graphing Logarithmic Functions:

  1. Start from inverse relationship with exponential
  2. Plot key point \((1,0)\)
  3. Identify vertical asymptote
  4. Apply transformations if needed
Key Idea: Exponential graphs grow, logarithmic graphs scale.

Common Mistakes

  • Confusing domain and range:
    Exponential and logarithmic functions have opposite restrictions.
  • Incorrect asymptotes:
    Exponential functions have horizontal asymptotes, logarithmic functions have vertical ones.
  • Forgetting key points:
    Not using \((0,1)\) or \((1,0)\) leads to inaccurate graphs.
  • Misidentifying transformations:
    Shifts inside vs. outside the function change direction.
  • Ignoring domain restrictions after shifts:
    Shifting logarithmic functions changes where the graph is defined.
  • Graphing before analyzing:
    Always identify features first.

Summary

  • Exponential functions have horizontal asymptotes.
  • Logarithmic functions have vertical asymptotes.
  • Key points help anchor graphs.
  • Transformations shift or reflect graphs.
  • Understanding structure allows accurate graphing.
