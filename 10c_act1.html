10.C Solving Exponential and Logarithmic Equations

Round Table

Exponential and Logarithmic Equations Activity
Problem 1
Solve the equation by rewriting both sides with a common base.
$$3^x = 81$$
Solution 1

Rewrite $81$ as a power of $3$.

$$81 = 3^4$$

Now the equation is

$$3^x = 3^4$$

When the bases are the same, the exponents must be equal.

$$x = 4$$
Problem 2
Solve the logarithmic equation.
$$\log_2 x = 5$$
Solution 2

Rewrite the logarithmic equation in exponential form.

$$2^5 = x$$

Evaluate the power.

$$x = 32$$
Problem 3
Solve the equation by combining logarithms first.
$$\log x + \log(x-1) = \log 20$$
Solution 3

Use the product property of logarithms.

$$\log[x(x-1)] = \log 20$$

If the logs are equal, their arguments are equal.

$$x(x-1)=20$$
$$x^2-x-20=0$$

Factor the quadratic.

$$(x-5)(x+4)=0$$
$$x=5 \text{ or } x=-4$$

Check domain restrictions: both $x$ and $x-1$ must be positive, so $x>1$.

$$\boxed{x=5}$$
Problem 4
Solve the exponential equation.
$$2^{x+3} = 64$$
Solution 4

Rewrite $64$ as a power of $2$.

$$64 = 2^6$$

Now solve by equating exponents.

$$2^{x+3} = 2^6$$
$$x+3=6$$
$$x=3$$
Problem 5
Solve the equation.
$$\ln x = 2$$
Solution 5

Rewrite the natural logarithm in exponential form.

$$e^2 = x$$

So the exact solution is

$$\boxed{x=e^2}$$
Problem 6
Solve by using a common base.
$$9^x = 3^8$$
Solution 6

Rewrite $9$ as $3^2$.

$$(3^2)^x = 3^8$$
$$3^{2x} = 3^8$$

Set the exponents equal.

$$2x=8$$
$$x=4$$
Problem 7
Solve the logarithmic equation.
$$\log x = 3$$
Solution 7

A common logarithm has base $10$.

$$10^3 = x$$
$$x=1000$$
Problem 8
Solve the equation. Give an exact answer.
$$2^x = 7$$
Solution 8

The two sides do not have a common base, so use logarithms.

$$2^x=7$$

Take the logarithm of both sides or rewrite directly in logarithmic form.

$$x=\log_2 7$$

An equivalent form is

$$x=\frac{\ln 7}{\ln 2}$$
Problem 9
Solve the equation.
$$\log(x+4)-\log x = \log 2$$
Solution 9

Use the quotient property of logarithms.

$$\log\left(\frac{x+4}{x}\right)=\log 2$$

Set the arguments equal.

$$\frac{x+4}{x}=2$$

Solve the rational equation.

$$x+4=2x$$
$$x=4$$

Check the domain: $x>0$, so $x=4$ is valid.

Problem 10
Solve the equation.
$$2\ln x = \ln 49$$
Solution 10

Use the power property of logarithms.

$$\ln(x^2)=\ln 49$$

Set the arguments equal.

$$x^2=49$$
$$x=\pm 7$$

Because the original expression is $\ln x$, we need $x>0$.

$$\boxed{x=7}$$
Problem 11
Solve the equation.
$$3^{x-1} = 27$$
Solution 11

Rewrite $27$ as a power of $3$.

$$27=3^3$$
$$3^{x-1}=3^3$$
$$x-1=3$$
$$x=4$$
Problem 12
Solve the logarithmic equation.
$$\log_5 x = -1$$
Solution 12

Rewrite in exponential form.

$$5^{-1}=x$$
$$x=\frac{1}{5}$$
Problem 13
Solve the equation.
$$8^x = 2^{x+6}$$
Solution 13

Rewrite $8$ as $2^3$.

$$(2^3)^x = 2^{x+6}$$
$$2^{3x}=2^{x+6}$$

Set exponents equal.

$$3x=x+6$$
$$2x=6$$
$$x=3$$
Problem 14
Solve the equation.
$$\log(x+1)+\log(x-3)=\log 28$$
Solution 14

Combine the logarithms.

$$\log[(x+1)(x-3)] = \log 28$$

Set the arguments equal.

$$(x+1)(x-3)=28$$
$$x^2-2x-3=28$$
$$x^2-2x-31=0$$

Use the quadratic formula.

$$x=\frac{2\pm\sqrt{128}}{2}=1\pm4\sqrt{2}$$

Check the domain. We need $x+1>0$ and $x-3>0$, so $x>3$.

$$\boxed{x=1+4\sqrt{2}}$$
Problem 15
Solve the equation exactly.
$$e^{2x} = 11$$
Solution 15

Take the natural logarithm of both sides.

$$\ln(e^{2x})=\ln 11$$
$$2x=\ln 11$$
$$x=\frac{\ln 11}{2}$$
Problem 16
Compare the solutions to the two equations.
$$\log x = 2 \qquad \text{and} \qquad \log(x-3)=2$$
Solution 16

First equation:

$$\log x=2 \Rightarrow x=100$$

Second equation:

$$\log(x-3)=2 \Rightarrow x-3=100 \Rightarrow x=103$$

The second solution is 3 greater because the input was shifted right by 3.

Problem 17
Solve the equation.
$$4^x = 32$$
Solution 17

A common base is not obvious until we rewrite both sides as powers of $2$.

$$4^x=(2^2)^x=2^{2x}$$
$$32=2^5$$
$$2^{2x}=2^5$$
$$2x=5$$
$$x=\frac{5}{2}$$
Problem 18
Solve and check for extraneous solutions.
$$\log(x-2)+\log(x-5)=\log 14$$
Solution 18

Combine the logarithms.

$$\log[(x-2)(x-5)] = \log 14$$
$$(x-2)(x-5)=14$$
$$x^2-7x+10=14$$
$$x^2-7x-4=0$$

Use the quadratic formula.

$$x=\frac{7\pm\sqrt{65}}{2}$$

The domain requires $x-2>0$ and $x-5>0$, so $x>5$.

Only the larger value works.

$$\boxed{x=\frac{7+\sqrt{65}}{2}}$$
Problem 19
Solve the equation.
$$5^{x+1} = 125^{x-1}$$
Solution 19

Rewrite $125$ as $5^3$.

$$5^{x+1} = (5^3)^{x-1}$$
$$5^{x+1}=5^{3x-3}$$

Set the exponents equal.

$$x+1=3x-3$$
$$4=2x$$
$$x=2$$
Problem 20
Explain why checking solutions matters when solving logarithmic equations.
Solution 20

Logarithms are only defined when their arguments are positive.

During the algebra, especially after combining logs or solving a quadratic, you can produce values that make one of the original log expressions undefined.

Checking each candidate solution in the original equation removes extraneous answers and makes sure the solution is actually valid.

For example, if a solution makes $x-1\le 0$ in $\log(x-1)$, that value must be rejected.
