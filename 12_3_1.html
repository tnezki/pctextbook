12.3.1 What can I expect from a random variable?

Expected Value of a Discrete Random Variable
12-129

Consider the discrete random variable \(X\) with the following distribution.

\(X\) \(5\) \(6\) \(8\) \(12\)
\(P(X)\) \(0.2\) \(0.1\) \(0.3\) \(0.4\)

  1. Explain why this is a valid probability model.

  2. Create a relative frequency histogram for this probability distribution.

  3. Calculate the expected value of \(X\).
