Level 5 — Conceptual & Justification

  1. Vertical asymptotes occur where the denominator equals zero, making the function undefined.
  2. The function can never equal a value where the denominator is zero, so the graph approaches but never crosses the vertical asymptote.
  3. Parameter \(h\) shifts the graph horizontally and determines the vertical asymptote \(x=h\).
  4. Parameter \(a\) controls vertical stretch/compression and reflection across the x-axis when negative.
  5. The vertical asymptote splits the domain into two intervals, creating two separate branches.
