Solutions

Section 8.A — Factor Expressions

1. $10x^2 - 15x = 5x(2x - 3)$

2. $x^2 + 15x + 56 = (x + 7)(x + 8)$

3. $4x^2 + 12x + 5x + 15 = (4x + 5)(x + 3)$

4. $x^2 - 121 = (x - 11)(x + 11)$

5. $x^3 + 64 = (x + 4)(x^2 - 4x + 16)$

6. $27x^3 - 125 = (3x - 5)(9x^2 + 15x + 25)$

7. $6x^3 - 96x = 6x(x^2 - 16) = 6x(x - 4)(x + 4)$

8. $2x^3 + 8x^2 - 3x - 12 = (2x^2 - 3)(x + 4)$

9. $9x^4 - 16 = (3x^2 - 4)(3x^2 + 4)$

10. $5x^3 - 40x = 5x(x^2 - 8)$
