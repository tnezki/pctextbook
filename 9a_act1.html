9.A Graph Transformations of Rational Functions

Showdown

Showdown Directions
Setup: Groups of 4 • each with a whiteboard • rotate a Captain each round.

1. Read & Think (30s): Captain reads the problem. Silent think time.

2. Work Alone: Solve silently. No talking/peeking. Finish → flip board face-down + thumbs up.

3. SHOWDOWN! Captain calls it. Reveal answers together.
4. Check & Celebrate: If all correct → celebrate. If not → discuss, fix, teach each other, then celebrate.

5. Rotate Captain: Person to the left leads next round.

Good teamwork:
  • “Let me show you how I did that…”
  • “I see my mistake.”
  • “What method did you use?”
Avoid:
  • Showing work before “Showdown!”
  • Rushing teammates
  • Copying answers

Problem 4 Answer
Simplify, then compare to the parent function.
\( \frac{1}{x} \)
\( \frac{x+6}{x+2}-\frac{x+7}{x+2} \)

Combine over common denominator:
\( \frac{(x+6)-(x+7)}{x+2}=\frac{-1}{x+2} \)
So the function is \( f(x)=-\frac{1}{x+2} \).
VA: \(x=-2\), HA: \(y=0\)
