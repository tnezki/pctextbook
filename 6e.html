SECTION 6.E
Extended Skill: Structured Accumulation with Sigma Notation

Sigma notation gives us a compact way to represent repeated addition. Instead of writing many terms separately, we use structured notation to describe accumulation. This language allows us to express totals clearly and efficiently. Later in this course, summation notation will be used to represent accumulated quantities such as area under curves.

Learning Objectives

I can evaluate sigma notation by expanding and computing sums.

I can write repeated sums using sigma notation.

I can simplify summations using properties of sums.

I understand that sigma notation represents structured accumulation.

Key Vocabulary

Sigma Notation: A compact way to represent repeated addition using the symbol $\Sigma$.

Index: The variable that changes within the summation.

Lower Bound: The starting value of the index.

Upper Bound: The ending value of the index.

Accumulation: The process of adding quantities together over an interval.

Core Concept

The expression

$\sum_{i=a}^{b} f(i)$

means:

Add $f(i)$ as $i$ increases from $a$ to $b$.

Properties of Summation

  • Constants factor out: $\sum c f(i) = c \sum f(i)$
  • Sums separate: $\sum (f(i) + g(i)) = \sum f(i) + \sum g(i)$
  • The bounds determine how many terms are included.

Examples

Example 1 — Numeric Evaluation

Evaluate:

$\sum_{i=1}^{5} i^2$

Example 2 — Write Using Sigma

Write the sum

$3 + 6 + 9 + 12 + 15$

using sigma notation.

Example 3 — Functional Substitution

Let

$f(x) = x^2 - 3x$

Evaluate:

$\sum_{i=0}^{5} f(2i)$

Example 4 — Interpretation

What does the expression

$\sum_{i=3}^{7} f(i)$

represent in words?

Summary

  • Sigma notation represents structured accumulation.
  • It compresses repeated addition into compact form.
  • Properties allow simplification and organization.
  • This notation prepares us to represent accumulated quantities later in the course.

Practice Problems

Easy

1. Expand and evaluate: $\sum_{i=1}^{4} i$
2. Expand and evaluate: $\sum_{i=1}^{4} (2i)$
3. Expand and evaluate: $\sum_{i=0}^{3} (i + 1)$
4. Write the following using sigma notation: $5 + 10 + 15 + 20$
5. Write the following using sigma notation: $4 + 7 + 10 + 13$

Medium

6. Evaluate: $\sum_{k=0}^{3} (k^2 + 1)$
7. Let $f(x) = 2x + 1$. Evaluate: $\sum_{i=1}^{4} f(i)$
8. Let $f(x) = x^2 - 1$. Evaluate: $\sum_{i=1}^{3} f(i)$
9. Simplify and write as a formula in terms of $n$: $\sum_{k=1}^{n} 3k$
10. Separate and simplify: $\sum_{k=1}^{4} (2k + 3)$

Hard

11. Let $f(x) = x^2 - 3x$. Evaluate: $\sum_{i=0}^{5} f(2i)$
12. Evaluate: $\sum_{i=2}^{6} (i - 1)$
13. Separate and simplify: $\sum_{k=1}^{4} (2k^2 + 3k)$
14. Let $g(x) = 3x - 2$. Evaluate: $\sum_{i=0}^{4} g(i)$
15. Rewrite: $\sum_{i=1}^{4} (i^2 + 2i)$ as two separate summations.

Justify

16. Explain why constants can be factored out of a summation.
17. Explain how sigma notation represents accumulation.
18. In your own words, explain what the bounds in $\sum_{i=2}^{6} f(i)$ tell you about the total being calculated.
