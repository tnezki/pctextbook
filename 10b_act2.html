10.B Graph Exponential and Logarithmic Functions
Whiteboard Partners
Partner activity for graphing, describing, and comparing exponential and logarithmic functions.
Problem 1

For the exponential function below, identify the domain, range, horizontal asymptote, and whether the graph shows growth or decay.

$$f(x)=3^x$$
Solution 1
Step 1: An exponential function of the form $a^x$ has domain all real numbers as long as the base is positive and not equal to 1.
Step 2: Because outputs of $3^x$ are always positive, the range is $y>0$.
Step 3: The parent exponential graph approaches but never reaches the x-axis, so the horizontal asymptote is $y=0$.
Step 4: Since the base $3$ is greater than 1, the function represents exponential growth.
Answer: Domain: $(-\infty,\infty)$, Range: $(0,\infty)$, horizontal asymptote: $y=0$, growth.
Problem 2

Create a table with at least four points and use it to graph the logarithmic function.

$$g(x)=\log_2 x$$
Solution 2
Step 1: Choose x-values that are powers of 2 because those are easy to evaluate in a base-2 logarithm.
Step 2: Compute the outputs:
  • $\log_2\left(\tfrac14\right)=-2$ because $2^{-2}=\tfrac14$
  • $\log_2\left(\tfrac12\right)=-1$ because $2^{-1}=\tfrac12$
  • $\log_2(1)=0$ because $2^0=1$
  • $\log_2(2)=1$ because $2^1=2$
  • $\log_2(4)=2$ because $2^2=4$
Step 3: Plot the points $\left(\tfrac14,-2\right)$, $\left(\tfrac12,-1\right)$, $(1,0)$, $(2,1)$, and $(4,2)$.
Step 4: Draw a smooth increasing curve with vertical asymptote $x=0$.
Possible table: $\left(\tfrac14,-2\right)$, $\left(\tfrac12,-1\right)$, $(1,0)$, $(2,1)$, $(4,2)$.
Problem 3

Describe the transformations from the parent function and state the new horizontal asymptote.

$$h(x)=2^{x-3}+4$$
Solution 3
Step 1: The parent exponential function is $y=2^x$.
Step 2: Replacing $x$ with $x-3$ shifts the graph 3 units to the right.
Step 3: Adding 4 outside the function shifts the graph 4 units up.
Step 4: The parent asymptote $y=0$ also shifts up 4 units, so the new asymptote is $y=4$.
Answer: Shift right 3, shift up 4, horizontal asymptote $y=4$.
Problem 4

Identify the domain, range, and vertical asymptote of the function.

$$p(x)=\ln(x+5)$$
Solution 4
Step 1: The expression inside the logarithm must be positive.
Step 2: Solve $x+5>0$, which gives $x>-5$. That is the domain.
Step 3: A logarithmic function can produce any real output, so the range is all real numbers.
Step 4: The input becomes 0 at $x=-5$, so the graph has vertical asymptote $x=-5$.
Answer: Domain: $(-5,\infty)$, Range: $(-\infty,\infty)$, vertical asymptote: $x=-5$.
Problem 5

Compare the graphs of the two functions. Describe at least two similarities or differences.

$$y=2^x \qquad \text{and} \qquad y=2^x-3$$
Solution 5
Step 1: The second function subtracts 3 outside the exponential expression, so it is a vertical translation of the first graph.
Step 2: That means every point on $y=2^x$ moves down 3 units to create $y=2^x-3$.
Step 3: The original graph has horizontal asymptote $y=0$, while the translated graph has horizontal asymptote $y=-3$.
Step 4: Both graphs are increasing exponential growth curves with the same shape.
Answer: Same shape and both are increasing; $y=2^x-3$ is the graph of $y=2^x$ shifted down 3 units, so its asymptote changes from $y=0$ to $y=-3$.
Problem 6

Graph the function by starting with the parent logarithmic function. Give the transformation and identify the vertical asymptote.

$$q(x)=\log_3(x-2)-1$$
Solution 6
Step 1: The parent function is $y=\log_3 x$.
Step 2: Replacing $x$ with $x-2$ shifts the graph 2 units to the right.
Step 3: Subtracting 1 outside the logarithm shifts the graph 1 unit down.
Step 4: The parent vertical asymptote is $x=0$; shifting right 2 gives the new asymptote $x=2$.
Step 5: Useful points come from the parent points $(1,0)$, $(3,1)$, and $\left(\tfrac13,-1\right)$. After shifting right 2 and down 1, they become $(3,-1)$, $(5,0)$, and $\left(\tfrac73,-2\right)$.
Answer: Shift right 2 and down 1; vertical asymptote $x=2$.
Problem 7

Determine whether the function is exponential growth or exponential decay. Then state the y-intercept and horizontal asymptote.

$$r(x)=\left(\frac13\right)^x$$
Solution 7
Step 1: In an exponential function $a^x$, if $0<a<1$, the graph shows exponential decay.
Step 2: Here the base is $\tfrac13$, which is between 0 and 1, so the function is decay.
Step 3: The y-intercept occurs when $x=0$: $r(0)=\left(\tfrac13\right)^0=1$.
Step 4: The parent exponential asymptote is unchanged, so the horizontal asymptote is $y=0$.
Answer: Exponential decay, y-intercept $(0,1)$, horizontal asymptote $y=0$.
Problem 8

The two functions below are inverses. Explain how you can tell from their equations and describe how their graphs are related.

$$y=5^x \qquad \text{and} \qquad y=\log_5 x$$
Solution 8
Step 1: A logarithmic function with base 5 undoes an exponential function with base 5.
Step 2: If $y=5^x$, then switching x and y gives $x=5^y$, which is equivalent to $y=\log_5 x$.
Step 3: Because inverse functions switch inputs and outputs, ordered pairs reverse. For example, $(1,5)$ on $y=5^x$ corresponds to $(5,1)$ on $y=\log_5 x$.
Step 4: Graphs of inverse functions are reflections across the line $y=x$.
Answer: They are inverses because logarithms undo exponentials with the same base, and their graphs reflect across $y=x$.
Problem 9

Identify the key features of the graph: domain, range, horizontal asymptote, and one convenient point to plot first.

$$s(x)=4^{x+1}-2$$
Solution 9
Step 1: This is an exponential function, so the domain is all real numbers.
Step 2: The parent function $4^x$ has range $y>0$. Shifting down 2 changes the range to $y>-2$.
Step 3: The parent asymptote $y=0$ shifts down 2 units, so the horizontal asymptote is $y=-2$.
Step 4: A convenient point comes from making the exponent 0: if $x+1=0$, then $x=-1$. So $s(-1)=4^0-2=1-2=-1$, giving point $(-1,-1)$.
Answer: Domain: $(-\infty,\infty)$, Range: $(-2,\infty)$, horizontal asymptote: $y=-2$, useful point: $(-1,-1)$.
Problem 10

State the domain, range, and x-intercept of the logarithmic function.

$$t(x)=\log(x)-2$$
Solution 10
Step 1: The logarithm requires $x>0$, so the domain is $(0,\infty)$.
Step 2: A vertical shift does not change the range of a logarithmic function, so the range is still all real numbers.
Step 3: To find the x-intercept, set the function equal to 0:
$$\log(x)-2=0$$
Step 4: Solve:
$$\log(x)=2$$
Since this is common log, $x=10^2=100$.
Answer: Domain: $(0,\infty)$, Range: $(-\infty,\infty)$, x-intercept $(100,0)$.
Problem 11

Sketch the graph of the function using three transformed key points from the parent exponential graph.

$$u(x)=-2^x+1$$
Solution 11
Step 1: Start with the parent points for $y=2^x$: $(-1,\tfrac12)$, $(0,1)$, and $(1,2)$.
Step 2: The negative sign reflects the graph across the x-axis, giving $(-1,-\tfrac12)$, $(0,-1)$, and $(1,-2)$.
Step 3: Adding 1 shifts every point up 1 unit, so the transformed points are $(-1,\tfrac12)$, $(0,0)$, and $(1,-1)$.
Step 4: The original asymptote $y=0$ shifts up to $y=1$.
Answer: Reflect across the x-axis, then shift up 1. Sample points: $(-1,\tfrac12)$, $(0,0)$, $(1,-1)$; horizontal asymptote $y=1$.
Problem 12

For the function below, identify the vertical asymptote and use it to explain the domain.

$$v(x)=\log_4(x+1)+3$$
Solution 12
Step 1: The expression inside the logarithm must stay positive, so solve $x+1>0$.
Step 2: This gives $x>-1$, so the domain is $(-1,\infty)$.
Step 3: The boundary value $x=-1$ makes the logarithm input 0, which is where the graph has a vertical asymptote.
Step 4: The +3 shifts the graph up but does not change the asymptote or domain restriction.
Answer: Vertical asymptote $x=-1$; domain $(-1,\infty)$.
Problem 13

Explain how the graph of the function compares to the parent graph $y=\ln x$.

$$w(x)=\ln(2x)$$
Solution 13
Step 1: Replacing $x$ with $2x$ creates a horizontal compression by a factor of $\tfrac12$.
Step 2: Another way to see this is by using log properties: $\ln(2x)=\ln 2+\ln x$.
Step 3: That means the graph is also the graph of $y=\ln x$ shifted up by $\ln 2$.
Step 4: The domain remains $x>0$, and the vertical asymptote is still $x=0$.
Answer: Compared to $y=\ln x$, the graph is horizontally compressed (or equivalently shifted up by $\ln 2$ using log properties). Domain $x>0$, asymptote $x=0$.
Problem 14

Identify a helpful table of points for graphing the function, then state whether the graph increases or decreases.

$$y=\left(\frac12\right)^{x-1}+2$$
Solution 14
Step 1: Make the exponent $x-1$ equal to $-1$, 0, and 1 to get easy values. That gives $x=0,1,2$.
Step 2: Evaluate:
  • $x=0$: $\left(\tfrac12\right)^{-1}+2=2+2=4$
  • $x=1$: $\left(\tfrac12\right)^0+2=1+2=3$
  • $x=2$: $\left(\tfrac12\right)^1+2=\tfrac12+2=\tfrac52$
Step 3: Since the base is $\tfrac12$, the function is exponential decay, so the graph decreases from left to right.
Possible table: $(0,4)$, $(1,3)$, $(2,\tfrac52)$. The graph decreases.
Problem 15

State the x-intercept and one other key point you would use to graph the logarithmic function.

$$y=\log_5(x-4)$$
Solution 15
Step 1: The x-intercept happens when $y=0$.
Step 2: Solve $\log_5(x-4)=0$. This means $x-4=5^0=1$, so $x=5$.
Step 3: A second convenient point comes from making $x-4=5$, because $\log_5(5)=1$. Then $x=9$, so $(9,1)$ is on the graph.
Step 4: You could also use $x-4=\tfrac15$ to get point $\left(\tfrac{21}{5},-1\right)$.
Answer: x-intercept $(5,0)$. Another easy point is $(9,1)$.
Problem 16

Which function has the steeper growth, and how can you tell from the base?

$$y=2^x \qquad \text{or} \qquad y=6^x$$
Solution 16
Step 1: Both functions are exponential growth because their bases are greater than 1.
Step 2: For growth functions, a larger base means the outputs multiply faster as x increases.
Step 3: Since $6>2$, the graph of $y=6^x$ rises more quickly than the graph of $y=2^x$.
Answer: $y=6^x$ has the steeper growth because it has the larger base.
Problem 17

Find the domain and explain why the function cannot be graphed for all real x-values.

$$y=\log(7-x)$$
Solution 17
Step 1: The logarithm input must be positive, so solve $7-x>0$.
Step 2: Subtract 7 or rewrite to get $x<7$.
Step 3: That means the domain is $(-\infty,7)$.
Step 4: If $x\ge 7$, then $7-x\le 0$, and logarithms of 0 or negative numbers are undefined in the real number system.
Answer: Domain: $(-\infty,7)$. The graph cannot include $x\ge 7$ because the log input would not be positive.
Problem 18

Explain why the graph of the function never crosses its horizontal asymptote.

$$y=3^x+1$$
Solution 18
Step 1: The parent function $3^x$ is always positive, so $3^x>0$ for every real x.
Step 2: Adding 1 gives $3^x+1>1$ for every real x.
Step 3: The horizontal asymptote is $y=1$, but the outputs are always greater than 1.
Step 4: Because the function can get very close to 1 without ever equaling 1, the graph approaches the asymptote but never crosses it.
Answer: The asymptote is $y=1$, and since $3^x+1$ is always greater than 1, the graph never crosses that line.
Problem 19

Describe the transformations of the function and state the domain, range, and vertical asymptote.

$$y=-\log_2(x-1)+4$$
Solution 19
Step 1: Start from the parent function $y=\log_2 x$.
Step 2: Replacing $x$ with $x-1$ shifts the graph right 1 unit.
Step 3: The negative sign reflects the graph across the x-axis.
Step 4: Adding 4 shifts the graph up 4 units.
Step 5: The input restriction is $x-1>0$, so $x>1$. Therefore the domain is $(1,\infty)$ and the vertical asymptote is $x=1$.
Step 6: Logarithmic functions still have all real outputs after reflections and vertical shifts, so the range is $(-\infty,\infty)$.
Answer: Right 1, reflect across the x-axis, up 4. Domain: $(1,\infty)$, Range: $(-\infty,\infty)$, vertical asymptote: $x=1$.
Problem 20

A student says, “Every logarithmic graph is decreasing because it has an asymptote.” Decide whether the statement is true or false and justify your answer.

Solution 20
Step 1: The statement is false.
Step 2: Whether a logarithmic graph increases or decreases depends on the base.
Step 3: If the base is greater than 1, such as $\log_2 x$, the graph is increasing.
Step 4: If the base is between 0 and 1, the graph is decreasing.
Step 5: Having a vertical asymptote does not determine whether the graph increases or decreases.
Answer: False. Some logarithmic functions increase and some decrease; the base determines the behavior, not the asymptote alone.
