SECTION 6.C

Connect Intercepts to Factors and Write Equations

In reverse, you can use a graph or a description of intercepts to write a polynomial equation. This skill moves you from the concrete (the picture) to the abstract (the algebra). If you know where a parabola crosses the axes, you can determine its equation. This is powerful because it lets you model real situations algebraically based on graphical information.

Learning Objectives

  • I can connect x and y intercepts on a graph to the factors and terms of a polynomial equation.
  • I can write the equation of a polynomial function given its graph, reasoning abstractly about coefficients and factors.
  • I can sketch polynomial graphs from sign charts and determine y-intercepts by attending to precision in algebraic computations.

Introduction: From Graph to Equation

When you see a graph, you can identify key features visually: where it crosses the axes, its shape, and how it behaves at infinity. But behind every graph is an equation. By analyzing the intercepts, you can reason backward to find the algebraic expression. This process combines visual thinking with abstract reasoning—two essential skills in mathematics.

Real-World Connection

Data scientists often work with scatter plots showing real phenomena: sales over time, temperature changes, or population trends. Once they identify the pattern visually, they write equations to predict future values. Engineers designing structures might be given visual specifications and need to determine the mathematical equations controlling them. This skill connects what you see to what you can calculate.

Historical Note: The connection between geometric curves and algebraic equations was formalized by René Descartes in the 17th century through his development of analytic geometry. This breakthrough allowed mathematicians to move fluidly between the visual and algebraic representations.

Key Vocabulary and Concepts

X-intercept: A point where the graph crosses the x-axis, found by setting $y = 0$. For a polynomial, these are the roots.
Y-intercept: A point where the graph crosses the y-axis, found by setting $x = 0$. For a polynomial $f(x)$, this is $f(0)$.
Leading Coefficient: The coefficient of the term with the highest power. This value determines whether the graph eventually goes up or down and can be used to scale the polynomial correctly.

Writing Equations from Roots

If you know the roots of a polynomial, you can immediately write it in factored form:

If roots are $r_1, r_2, \ldots, r_n$, then:

$$f(x) = a(x - r_1)(x - r_2) \cdots (x - r_n)$$

where $a$ is a leading coefficient you need to find.

Using the Y-Intercept to Find the Leading Coefficient

Once you have the factored form with unknown $a$, substitute $x = 0$ and the known y-intercept to solve for $a$. This single additional piece of information completely determines the polynomial.

Example Problems

Example 1: Writing an Equation from X-Intercepts

Problem: A parabola crosses the x-axis at $x = -3$ and $x = 5$. Its y-intercept is $(0, -15)$. Write the equation in factored form.

Solution: Since the roots are $x = -3$ and $x = 5$, the factored form is: $f(x) = a(x + 3)(x - 5)$

Use the y-intercept to find $a$. Substitute $x = 0$ and $f(0) = -15$:

$$-15 = a(0 + 3)(0 - 5)$$ $$-15 = a(3)(-5)$$ $$-15 = -15a$$ $$a = 1$$

Equation: $f(x) = (x + 3)(x - 5) = x^2 - 2x - 15$

Expanded form: $f(x) = x^2 - 2x - 15$

Example 2: Determining Multiplicity from a Graph

Problem: A polynomial graph touches the x-axis at $x = 2$ without crossing and crosses at $x = -1$. The y-intercept is $(0, 8)$. Write a possible equation.

Solution: Touching without crossing means $x = 2$ has even multiplicity. Crossing means $x = -1$ has odd multiplicity. A simple choice is multiplicity 2 for $x = 2$ and multiplicity 1 for $x = -1$:

$$f(x) = a(x + 1)(x - 2)^2$$

Use the y-intercept. Substitute $x = 0$ and $f(0) = 8$:

$$8 = a(0 + 1)(0 - 2)^2$$ $$8 = a(1)(4)$$ $$8 = 4a$$ $$a = 2$$

Equation: $f(x) = 2(x + 1)(x - 2)^2$

Expanded: $f(x) = 2(x + 1)(x^2 - 4x + 4) = 2(x^3 - 4x^2 + 4x + x^2 - 4x + 4) = 2(x^3 - 3x^2 + 4) = 2x^3 - 6x^2 + 8$

Example 3: Three X-Intercepts and Finding Coefficients

Problem: A cubic polynomial crosses the x-axis at $x = -2, 0, 3$. It passes through the point $(1, -6)$. Write the equation.

Solution: With roots at $x = -2, 0, 3$, the factored form is: $f(x) = a(x + 2)(x)(x - 3)$

Use the point $(1, -6)$ to find $a$. Substitute $x = 1$ and $f(1) = -6$:

$$-6 = a(1 + 2)(1)(1 - 3)$$ $$-6 = a(3)(1)(-2)$$ $$-6 = -6a$$ $$a = 1$$

Equation: $f(x) = (x + 2)(x)(x - 3) = x(x + 2)(x - 3)$

Expanded: $f(x) = x(x^2 - x - 6) = x^3 - x^2 - 6x$

Example 4: Writing from a Sign Chart

Problem: A polynomial has a sign chart showing negative for $x < -2$, positive for $-2 < x < 4$, and negative for $x > 4$. The y-intercept is 16. Write a possible equation.

Solution: The sign changes at $x = -2$ and $x = 4$ indicate roots. The sign pattern suggests the polynomial crosses at both (odd multiplicity). A simple choice is $f(x) = a(x + 2)(x - 4)$ for a quadratic.

However, for a quadratic with positive leading coefficient, both ends go up, contradicting the negative regions at both ends. So $a < 0$. Using the y-intercept $(0, 16)$:

$$16 = a(0 + 2)(0 - 4)$$ $$16 = a(2)(-4)$$ $$16 = -8a$$ $$a = -2$$

Equation: $f(x) = -2(x + 2)(x - 4)$

Expanded: $f(x) = -2(x^2 - 2x - 8) = -2x^2 + 4x + 16$

The negative leading coefficient $-2$ makes both ends go downward, matching the sign chart.

Summary of Key Concepts

  • X-intercepts correspond to roots: If the graph crosses the x-axis at $x = r$, then $f(r) = 0$ and $(x - r)$ is a factor.
  • Factored form from roots: If you know all roots, you can immediately write $f(x) = a(x - r_1)(x - r_2) \cdots (x - r_n)$.
  • The y-intercept provides crucial information to find the leading coefficient $a$. Substitute $(0, b)$ into your equation with unknown $a$ and solve.
  • If the graph bounces at a root, that root has even multiplicity. If it crosses, odd multiplicity.
  • Sign charts tell you about roots and multiplicity: Where the sign changes, there's a root with odd multiplicity. Where it doesn't change, even multiplicity.
  • Additional points help determine multiplicity: If you know a point on the graph other than intercepts, you can determine the exact equation.
  • End behavior helps determine the sign of the leading coefficient: If the right end goes up, the leading coefficient is positive. If it goes down, the leading coefficient is negative.
  • Abstract reasoning connects visual and algebraic: Moving from a graph to an equation requires thinking about what the visual features mean algebraically.

Practice Problems

Problem 1 (Easy): A parabola has x-intercepts at $x = 2$ and $x = -3$. Write the factored form with an unknown leading coefficient $a$.
Problem 2 (Easy): The polynomial $f(x) = 2(x - 1)(x + 4)$ passes through which points? Find the x-intercepts and y-intercept.
Problem 3 (Medium): A parabola has x-intercepts at $x = -1$ and $x = 3$, and y-intercept at $(0, 6)$. Find the leading coefficient and write the equation.
Problem 4 (Medium): A cubic polynomial has roots at $x = 0, 2, -2$ and passes through the point $(1, 3)$. Write the equation in expanded form.
Problem 5 (Medium): A graph touches the x-axis at $x = 1$ without crossing and crosses at $x = -3$. The y-intercept is $(0, -2)$. Write a possible equation.
Problem 6 (Harder): From the given sign chart with negative for $x < 1$, positive for $1 < x < 4$, negative for $x > 4$, and y-intercept $(0, -8)$, write the equation for a quadratic polynomial.
Problem 7 (Harder): A polynomial has a double root (multiplicity 2) at $x = 0$ and simple roots at $x = 2$ and $x = -2$. The graph passes through the point $(1, -2)$. Write the equation.
Problem 8 (Harder): A polynomial of degree 4 bounces at $x = 1$ and $x = -2$, crosses at $x = 3$, and has y-intercept $(0, 12)$. Determine the equation (with the fifth multiplicity distributed as needed).

Answer Key

Answer 1: With roots at $x = 2$ and $x = -3$, the factored form is $f(x) = a(x - 2)(x + 3)$.
Answer 2: X-intercepts: Set $f(x) = 0$: $2(x - 1)(x + 4) = 0$ gives $x = 1$ and $x = -4$. Points: $(1, 0)$ and $(-4, 0)$. Y-intercept: $f(0) = 2(0 - 1)(0 + 4) = 2(-1)(4) = -8$. Point: $(0, -8)$.
Answer 3: Start with $f(x) = a(x + 1)(x - 3)$. Using y-intercept $(0, 6)$: $6 = a(0 + 1)(0 - 3) = a(1)(-3) = -3a$, so $a = -2$. The equation is $f(x) = -2(x + 1)(x - 3) = -2(x^2 - 2x - 3) = -2x^2 + 4x + 6$.
Answer 4: With roots $0, 2, -2$, the form is $f(x) = a(x)(x - 2)(x + 2) = ax(x^2 - 4)$. Using point $(1, 3)$: $3 = a(1)(1 - 4) = a(1)(-3) = -3a$, so $a = -1$. The equation is $f(x) = -x(x^2 - 4) = -x^3 + 4x$.
Answer 5: The root at $x = 1$ with bouncing means multiplicity 2. The root at $x = -3$ crosses means multiplicity 1. So $f(x) = a(x - 1)^2(x + 3)$. Using y-intercept $(0, -2)$: $-2 = a(0 - 1)^2(0 + 3) = a(1)(3) = 3a$, so $a = -\frac{2}{3}$. The equation is $f(x) = -\frac{2}{3}(x - 1)^2(x + 3)$.
Answer 6: The sign changes at $x = 1$ and $x = 4$, indicating roots with odd multiplicity. For a quadratic, these are both multiplicity 1. So $f(x) = a(x - 1)(x - 4)$. The sign pattern (neg, pos, neg) with a quadratic requires $a < 0$. Using y-intercept $(0, -8)$: $-8 = a(0 - 1)(0 - 4) = a(1)(4) = 4a$, so $a = -2$. The equation is $f(x) = -2(x - 1)(x - 4) = -2x^2 + 10x - 8$.
Answer 7: Double root at $x = 0$ means multiplicity 2, simple roots at $x = 2, -2$. So $f(x) = ax^2(x - 2)(x + 2) = ax^2(x^2 - 4)$. Using point $(1, -2)$: $-2 = a(1)^2(1 - 4) = a(1)(-3) = -3a$, so $a = \frac{2}{3}$. The equation is $f(x) = \frac{2}{3}x^2(x^2 - 4)$.

Let me revise: For degree 4, if bouncing at $x = 1$ and $x = -2$ (multiplicity 2 each), that's degree 4.
